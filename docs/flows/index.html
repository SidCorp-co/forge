Flow diagrams

One file per flow. A flow is something that moves — a request across processes, a lifecycle, a decision path. Not a box diagram of what exists; docs/modules/ already owns structure.

Rules

  • Backfilled by the work, never as a project. An issue that touches a feature or module backfills that flow in the same change. Nobody is assigned to draw the missing ones.
  • One flow per file, named <domain>-<flow>.html, and listed in the table below in the same commit. A file not in the table is unreachable and counts as missing.
  • Show the mechanism. The test is whether a reader who has not seen the code can say what happens when it goes wrong. A diagram that only names the components has not earned its file.
  • Pick the form from the question — sequence when the point is who talks to whom and in what order; state machine when the point is which transitions are legal; flowchart when the point is where a decision forks. Inline SVG or a <pre class="mermaid"> block, self-contained, opens from disk with no build step.
  • An edge that leaves from EVERY node is a band, not N arrows. Draw it once as a labelled strip with a tick down to each node it touches. issue-status-lifecycle spent 29 of its 59 edges on three universal exits and rendered as a hairball; the same three facts are one band and one footer.
  • The figure is the page; prose is a caption. The landing view is the diagram, a legend, and at most three lines under it. Everything else goes in a tab or a table row. If a paragraph is needed to explain the diagram, fix the diagram.
  • Lay it out like a screen, not a document. A header bar naming the flow and its one-line status, the figure on its own panel, a right rail for the per-node reference, tabs for the detail. The reader is scanning, not reading top to bottom.
  • Hand-author the SVG when the layout carries meaning. A layout engine given 14 nodes packs them and shrinks the type until nobody reads it. Mermaid is right for a short chain; past ~10 nodes or ~20 edges, place them yourself. Keep the figure in a scrolling panel (overflow-x:auto) with its grid column at minmax(0,1fr), or a wide figure drags the whole page sideways.
  • Delete rather than carry. A flow the code no longer performs is removed in the change that discovers it — not marked stale.
