2 · The row — what exists, and what is added

assumed is the closest thing that exists to a default — but it records what an agent did after the fact. The destination asks for it before, and refuses a question without one.

Every question carries its own default, or says no default is safe.
This is the anti-spam mechanism, not a form field: an agent that can write a safe default usually should not have asked, and writing it down usually answers the question.

6 · Delivery is an act on the world, so it has a witness

A question reaches a human through a channel — a room, a thread, a reply on the message the question is about. That is an integration call like any other, so it obeys the same rule.

What happensWhat it means
delivereda delivery fact with the channel's own message id

nobody repliesT1, then T2 — the clocks are on the question, not on the channel
a reply arrivesinbound, verified, matched to the open question by its origin — never by guessing
the question has nowhere to gosay so once, to whoever runs the project. Post nothing, and never silently pick another room
The row is the truth; the delivery is a best effort. Losing a message must never lose a question — which is exactly why the question is a kernel row and not a chat message with state attached to it.

7 · An answer becomes policy in two steps

Promoted answers carry scope and valid_from and are superseded, never deleted — so a later answer retires an earlier one visibly.
