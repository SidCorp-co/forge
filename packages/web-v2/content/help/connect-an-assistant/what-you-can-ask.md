# What you can ask

Once your assistant is connected, ask it about your project the way you would
ask a colleague. The questions below are starting points: copy one, change the
issue number or the words to fit, and send it. Wherever a question says
`ISS-123`, use the number shown on one of your own issues.

Your assistant decides how to find the answer, and it can only see and change
what your own Forge account can. When an answer matters, check it on the issue's
page in Forge — that page is the record.

## What is going on

- "What issues are open in this project right now?"
- "Which issues are waiting for someone to answer a question?"
- "Which high-priority issues are still open?"
- "What is being worked on at the moment?"
- "Which issues are waiting to be released?"
- "Find the issues that mention the login page."
- "Which issues are blocked, and what is each one waiting for?"
- "How many issues are open, grouped by priority?"

## One issue

- "What is ISS-123 about, and what status is it at?"
- "Summarise the comments on ISS-123."
- "What does ISS-123 still need before it can move on?"
- "Has the work on ISS-123 been released yet?"

## Asking for a change

- "File an issue: the invoice PDF should show the customer's billing address."
- "Turn this bug report into an issue, and show me the text before you file it."
- "Add a comment to ISS-123 saying the fix works on my phone."
- "Answer the question on ISS-123: yes, use the blue button."
- "Set ISS-123 to high priority."

## About the project

- "Are any of this project's runners offline?"
- "What does this project's knowledge say about how releases work?"
- "What does the status Awaiting release mean?"

## Asking well

- **Name the issue number** when you mean one issue. It is the quickest way to
  point at exactly one.
- **Say what you want back.** Add "just the titles" or "one line each" when you
  want a short list.
- **Ask to see it first** when you want to read what will be filed or changed
  before it happens: add "show me before you do it" to any question that asks
  for a change.

For what each status means, see [Read an issue's status](?path=issue-statuses).
