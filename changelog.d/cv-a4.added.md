**The assistant can run a report query and draw it in the chat.** `forge_report` runs a registered query as the asker and keeps the run for 30 days; `forge_show` posts a table, key-figure or status-list block of that run into the room, and an agent session posts the same block through `POST /api/conversations/:id/blocks`. Each block shows the query and the time its run read. A block holding a figure its run never read, a run read as another member, and a run past its 30 days are each refused by name.
